# Location simulation · 位置模拟

Android 位置模拟项目展示，采用蓝白配色与圆形悬浮控件，提供地图交互、摇杆移动与路线回放界面。

> 当前仅作项目展示，暂不公开源码，也不提供 APK、安装包或软件下载渠道。

## 功能介绍

- 地图交互：普通图与卫星图切换、地图缩放与定位入口。
- 摇杆控制：控制模拟位置移动，中央锁定按钮可单独锁住摇杆输入。
- 路线管理：新建、保存和删除路线，并从路线列表选择播放。
- 路线回放：支持播放、暂停后继续，以及播放过程中切换步行、跑步和骑行速度档位。
- 悬浮面板：通过悬浮控件切换与操作摇杆和路线回放。
